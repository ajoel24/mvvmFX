# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | ✓         |
| 1.x     | ✗         |

## Reporting a Vulnerability

Please report security vulnerabilities privately by opening a GitHub issue
with the "security" label or by emailing the maintainer directly.

Do not disclose security issues publicly until a fix is released.
