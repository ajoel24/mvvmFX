# Contributing to mvvmFX

Thank you for your interest in contributing to this fork of mvvmFX.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Ensure you have Java 25 and Maven 3.9.6+ installed.
4. Build the project: `mvn clean verify -DskipTests`

## Making Changes

- Open an issue to discuss significant changes before investing effort.
- Create a feature branch from `main`.
- Follow the existing code style.
- Preserve original copyright headers and add your own copyright line for files you modify.
- Update `CHANGELOG.md` for user-visible changes.

## Submitting Changes

1. Run the full test suite: `mvn clean verify`
2. Commit with clear, descriptive messages.
3. Open a pull request against `main`.

## Code of Conduct

Be respectful and constructive. Harassment or abusive behavior will not be tolerated.
